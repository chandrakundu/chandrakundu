### Hi, I'm Chandra Kundu

Postdoctoral Scholar, School of Data, Mathematical, and Statistical Sciences, University of Central Florida. Ph.D. in Big Data Analytics (UCF, 2026).

I build scalable, deep learning-enhanced algorithms that recover structure from noisy, incomplete, or corrupted data.

- **Research:** robust matrix completion, Euclidean distance geometry, deep unfolding (learning to optimize)
- **Applications:** biomedical imaging, remote sensing, sensor localization, IoT
